# 峡谷快剪

面向《英雄联盟》全局对局等长视频的本地快速剪辑工具。素材全程在本机处理，不上传网络。

GitHub 仓库：

https://github.com/3272002347/canyon-quickcut

## 下载与安装

推荐下载最新安装版：

https://github.com/3272002347/canyon-quickcut/releases/latest

安装版支持自动检查、后台下载和一键重启安装更新。便携版无需安装，但不支持原地自动更新。

当前版本：`1.1.0`

## 多台电脑使用

1. 在新电脑上打开 GitHub Releases 最新版本页面。
2. 下载 `峡谷快剪-Setup-版本号-x64.exe`。
3. 双击安装，之后桌面和开始菜单会出现“峡谷快剪”。
4. 软件启动约 8 秒后自动检查更新，每 4 小时再次检查。
5. 发现新版本会自动下载，下载完成后点击底部“重启安装”即可。
6. 工程文件 `.cqcut` 只记录原视频路径，不复制原视频。跨电脑打开工程时，原视频需要放在可访问的位置；路径不一致时应重新导入原视频。

## 自动更新说明

- 自动更新以安装版 `Setup` 为准。
- 便携版会显示“便携版”，需要手动下载新版。
- 更新源为 GitHub Releases 的 `latest.yml` 和安装包。
- 当前安装包未做商业代码签名，Windows SmartScreen 可能提示“未知发布者”，可选择“更多信息 → 仍要运行”。
- 未签名不影响安装和自动更新，但公开分发给大量用户时建议后续购买代码签名证书。

## 主要功能

- 长视频流式预览，支持拖动进度与片段内跳转
- 多片段裁剪、分割、复制、删除、拖拽排序
- 0.25x 至 4x 变速
- 音量、静音、淡入、淡出
- 16:9、9:16、1:1、4:5 画布
- 完整显示 / 填满裁切
- 720P、1080P、4K 输出
- 30 / 60 FPS 输出
- 亮度、对比度、饱和度调整
- 水平 / 垂直翻转
- 文字图层、位置、字号、颜色、底色、透明度
- 撤销、重做、时间线缩放、吸附
- 剪辑工程保存与重新打开
- 精准导出与单片段快速导出
- H.264 + AAC MP4，可直接导入剪映继续创作
- GitHub Releases 自动检查更新

## 导出说明

- **精准导出**：逐帧处理变速、裁剪、画面滤镜、音量、淡入淡出和文字，适合最终成片。
- **快速导出**：只对单个不变速、无效果片段启用，不重新编码，切点会落在最近关键帧，速度最快但时间不绝对精确。
- 录屏建议使用 H.264 MP4。若源文件是 HEVC/H.265 且预览黑屏，仍通常可以导出，但直接使用 H.264 素材体验最好。
- 输出为 MP4，后续可在剪映中继续添加转场、音乐、贴纸和包装。

## 开发

源码启动：

`启动峡谷快剪.bat`

本地生成安装版和便携版：

`打包便携版.bat`

构建要求：Node.js 20+，Windows 10/11 x64。依赖安装和 Electron 下载默认使用国内镜像。

## 发布新版本

仓库使用 GitHub Actions 自动构建和发布 Windows 安装包。

1. 修改 `package.json` 中的版本号，例如 `1.1.1`。
2. 提交代码并推送 `main`。
3. 创建并推送对应的版本标签：

```powershell
git tag v1.1.1
git push origin v1.1.1
```

4. `.github/workflows/release.yml` 会自动完成类型检查、前端构建、NSIS 安装包、便携版和 GitHub Release。
5. 已安装旧版本的电脑会在下次启动或手动检查时收到更新。

自动更新依赖 GitHub Release 中的以下文件：

- `latest.yml`
- `峡谷快剪-Setup-版本号-x64.exe` 或对应的安全文件名
- `.blockmap` 差分更新文件

## 工程文件

工程扩展名为 `.cqcut`。工程只记录原视频路径和剪辑参数，不会复制或改动原始 1–2 GB 视频文件。移动原视频后，需要重新导入素材。
